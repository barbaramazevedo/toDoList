# 📝 To-Do List Manager

Sistema de gerenciamento de tarefas com múltiplas listas por usuário, permitindo organizar atividades por categorias e acompanhar o progresso das tarefas.

---

# 📌 Sobre o Projeto

Este projeto consiste na criação de uma aplicação de gerenciamento de tarefas (To-Do List), onde cada usuário pode possuir múltiplas listas personalizadas para organizar suas atividades.

Cada lista poderá conter diversas tarefas e também uma categoria específica para facilitar a classificação e organização das informações.

Neste módulo, o foco está no desenvolvimento das telas da aplicação e na navegação entre elas. Os dados utilizados serão mockados, ou seja, definidos diretamente no código HTML, sem integração com banco de dados ou backend neste momento.

---

# 🚀 Funcionalidades

## 👤 Usuários
- Criar um novo usuário.

## 📂 Listas de Tarefas
- Criar uma nova lista de tarefas.
- Remover uma lista de tarefas.
- Listar todas as listas de um usuário.
- Classificar listas por categorias.

## ✅ Tarefas
- Adicionar tarefas a uma lista.
- Listar todas as tarefas de uma lista.
- Marcar tarefas como concluídas.
- Remover tarefas de uma lista.

---

# 🏷️ Categorias das Listas

Cada lista poderá possuir uma categoria para melhorar a organização das tarefas.

### Exemplos:
- Trabalho
- Estudos
- Pessoal
